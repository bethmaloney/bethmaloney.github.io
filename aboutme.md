## What I Do

At **Interfi Systems** I've led the migration from WinForms/ASP.NET to React and ASP.NET Core, delivered NAB PayID, Shaype cards and Banked PayTo integrations end-to-end, and designed webhook infrastructure for the Capital platform to make payment events more reliable and transparent.

I prioritise **reliability** and **security** – implementing CI/CD pipelines, feature flags (LaunchDarkly), Azure Monitor, and GitHub Dependabot (taking vulnerabilities from 200+ down to zero).

I also focus on **how teams ship software**. I've driven agile transformation and rolled out tools like CodeRabbit and GitHub Copilot to boost code review quality and developer productivity.
